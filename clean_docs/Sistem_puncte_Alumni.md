| --- | --- | --- | --- |
| Punctele se dau după profilul task-ului pe 5 factori, nu după departament. Un task de 5 puncte are aceeași greutate oriunde. |  |  |  |
|  |  |  |  |
| Cei 5 factori de complexitate (fiecare 1–5) |  |  |  |
| Factor | 1 — minim | 3 — mediu | 5 — maxim |
| Timp efectiv de muncă | câteva minute | 1–2 ore | multe ore / mai multe sesiuni |
| Competență / skill | oricine poate | necesită ceva pricepere | skill tehnic/creativ specializat |
| Efort cognitiv / creativ | pură execuție | ceva gândire proprie | design, creație de la zero |
| Coordonare & dependințe | solo | o persoană / o dependință | mai multe persoane / departamente |
| Responsabilitate / miză | intern, low-stakes | vizibilitate medie | public, reprezintă brandul |
|  |  |  |  |
| Scala de puncte (suma celor 5 factori → puncte) |  |  |  |

| 8–10 | 8 | 2 | Simplu |

| 14–17 | 14 | 5 | Moderat-complex (referință) |
| 18–21 | 18 | 8 | Complex |
| 22–25 | 22 | 13 | Major / proiect |

| Reguli speciale & decizii de luat |  |
| --- | --- |
|  |  |
| Recurente → abonamente | Moderare Discord, apeluri, liaison se punctează ca pachet pe perioadă (ex. moderare = 3 pct/săpt.), nu firimitură cu firimitură. |
| Task-uri partajate | Fiecare rol se punctează separat pe sub-task-ul lui — NU împarți un buget fix. Ex. seară educativă: Comunicare 3 + Comunitati 5 + Tehnic 5. |
| Multiplicator Core-Team | ×1.5 pe punctele activității deținute cap-coadă (recompensează ownership-ul). |
| Bonus de consistență | +2 pct/săptămână pentru cine acoperă fiabil un abonament recurent — antidot ca task-urile plictisitoare să nu fie demotivate de re-ponderare. |
| Ore vs. Puncte | Păstrează 2 coloane în Document puncte: Ore (raportare/contract) și Puncte (complexitate → clasament + codecoins). |
